Quick one-time setup

Browsers can't start apps on their own, so desktop needs a small open-source helper.

Desktop Linux & macOS

1
Install mpv and yt-dlp
# Linux
$ sudo pacman -S mpv yt-dlp
# macOS
$ brew install mpv yt-dlp
2
Install the helper
$ git clone https://github.com/TalhaAksoy/stream-to-mpv
$ cd stream-to-mpv && make
-> Clean GUI environment test OK & mpv ready!
3
Restart the browser and click mpv on any video

Android no helper needed

1
Install mpv-android
From Google Play, F-Droid or GitHub
(package is.xyz.mpv).
2
Tap ▶ mpv on a video
The stream opens straight in mpv-android. YouTube works without yt-dlp.
Private by design. No tracking or analytics. Stream URLs go only to mpv on your own device.

FirefoxChromeChromiumBraveEdgeVivaldiFirefox for AndroidLemur · Mises (Android)
